### Design Specificity Verdict

**LLM Assessment:**
Oern demonstrates impressive domain fidelity in its underlying mechanics: strict integer `MMK` Kyat handling without fractional currency, explicit `Asia/Yangon` (UTC+6:30) timezone locking, road intelligence accounting for Yangon monsoon flood zones, and custody-unit COD batch reconciliation. However, the visual and linguistic presentation suffers from a major domain disconnect: the UI is 100% English despite targeting Burmese-speaking couriers, and COD is modeled as physical-only cash despite Yangon's heavy reliance on KBZPay and WaveMoney digital doorstep transfers.

**Deterministic Scan Findings:**
- 2 `side-tab` anti-pattern warnings in `src/components/delivery/rider-jobs.css` (lines 151, 156: `border-left: 5px solid #f97316` and `border-left: 5px solid #ef4444`). These violate card uniformity and use Brand Orange as a status indicator.
- Foreign brand tokens detected in `rider-delivery.css` (lines 1736, 1843: hardcoded Grab green `#00b14f` instead of Oern Success `#16A34A`).
- Inverted map token fallbacks in `rider-flow.css` (lines 631–649).
- Skipped heading hierarchy in `pickup-request.tsx` (skips from `<h1>` to `<h6>` due to MUI `Typography variant="subtitle2"` default).

**Visual Overlays:**
No interactive browser overlay was injected (headless CLI detection environment; `.impeccable/live/config.json` not configured).

### Overall Impression
The order flow architecture is robust, exceptionally well-modeled for real-world logistical failure modes (stale GPS, offline retries, atomic RPCs, and decoupled COD payment states). The biggest opportunity is closing the gap between this industrial-grade backend and the real physical field conditions in Myanmar: introducing Burmese localization, digital COD options, and unifying the rider handover experience.

---

### What's Working
1. **Decoupled Delivery & Payment State Machine:** Order status (`pending` → `assigned` → `in_transit` → `delivered`) and payment status (`pending` → `collected` → `settled`) are completely orthogonal, preventing reconciliation deadlocks if a package is delivered with COD pending.
2. **Field-Resilient Handover Mechanics:** 300m arrival proximity checking, `SwipeConfirm` tactile interaction preventing accidental taps, and idempotent request tokens preventing duplicate network submissions.
3. **Driver-Custody COD Reconciliation:** The manager ledger groups money by rider shift rather than loose individual orders, matching the real-world depot cash pouch return process.

### Priority Issues

#### [P0] Hardcoded English-Only UI for Myanmar Couriers
- **Why it matters:** Motorbike riders navigating heavy Yangon traffic cannot decipher technical English error states or handover prompts.
- **Fix:** Implement Burmese localization (`my-MM` Unicode) for all driver task views and customer notifications.
- **Suggested command:** `$impeccable clarify`

#### [P1] Disorienting Handover Paradigm Switch on COD Deliveries
- **Why it matters:** In `rider-handover.tsx`, when `stop.codDue > 0`, the screen abruptly hides the parcel checklist and recipient input in favor of a single cash card with ambiguous copy ("Pay With MMK X").
- **Fix:** Keep a unified 3-step checklist across all deliveries: 1) Verify Parcels, 2) Verify Recipient, 3) Collect COD (if applicable). Change button label to "Collect MMK X from Customer".
- **Suggested command:** `$impeccable distill`

#### [P1] Foreign & Inverted Color Tokens Violating Design Contract
- **Why it matters:** Hardcoded Grab green (`#00b14f`) and Tailwind red (`#ef4444`) erode brand identity and break dark mode contracts. `rider-jobs.css` also uses brand orange as a status indicator.
- **Fix:** Replace hardcoded hex values with standard Oern tokens (`#16A34A` for success, `#DC2626` for error, neutral cards without colored side tabs).
- **Suggested command:** `$impeccable polish`

#### [P2] Unstructured Address Input in Pickup Flow
- **Why it matters:** Free-text addresses cause Mapbox reverse geocoding to fail in peripheral Yangon townships (e.g., Hlaingthaya, South Dagon).
- **Fix:** Add a structured Yangon Township selector dropdown before street and landmark text inputs.
- **Suggested command:** `$impeccable harden`

#### [P2] Skipped Heading Hierarchy in Customer Pickup Wizard
- **Why it matters:** `<Typography variant="subtitle2">` outputs `<h6>` elements directly after `<h1>`, breaking screen reader document outlines.
- **Fix:** Explicitly set `component="h2"` or `component="span"` on section subtitles.
- **Suggested command:** `$impeccable audit`

#### [P3] Absence of Digital Doorstep COD (KPay / WaveMoney)
- **Why it matters:** Customers paying amounts >50,000 MMK often demand digital transfers, which currently trigger false "cash discrepancy" reports.
- **Fix:** Add a payment method toggle: Cash vs KBZPay/Wave with optional transaction reference field.
- **Suggested command:** `$impeccable shape`
