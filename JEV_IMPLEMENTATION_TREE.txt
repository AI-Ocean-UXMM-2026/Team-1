=== DATA FLOW ===

Input: Complaint text (max 2000 chars)
    ↓
Classification Service
    ├─ Jev Mode (with API key):
    │  └─→ TypeSafeClient → OpenRouter API → Jev-1.14
    │      ├─→ Returns category + confidence
    │      └─→ Returns priority + confidence
    │
    └─ Mock Mode (no API key):
       └─→ Pattern matching on keywords
           ├─→ Detects P1: threats, security, safety
           ├─→ Detects P2: financial, fraud
           ├─→ Detects P3: standard operational
           └─→ Detects P4: feedback, questions
    ↓
Output: Classification Result
    ├─ category: string (13 types)
    ├─ categoryConfidence: 0-1
    ├─ priority: "P1"|"P2"|"P3"|"P4"
    ├─ priorityConfidence: 0-1
    ├─ mode: "jev"|"mock"
    └─ appPriority: "urgent"|"high"|"normal"|"low"
