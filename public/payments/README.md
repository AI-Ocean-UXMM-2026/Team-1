# Payment logos

Drop the licensed brand artwork here and the app uses it automatically:

- `mmqr.webp` — MMQR (Myanmar QR) mark
- `ctzpay.svg` — CTZPay mark

SVG or PNG (rename the extension in `src/components/delivery/payment-logos.tsx`).
Square artwork on a transparent or white background works best; it is shown at
28–44 px. Until a file exists the app shows a neutral icon instead.

These are not stored in the repository by default because the marks belong to
their owners; use the files you are licensed to use.
