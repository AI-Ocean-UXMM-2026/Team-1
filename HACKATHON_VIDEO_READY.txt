================================================================================
🔧 TROUBLESHOOTING
================================================================================

ERROR: "Port 3000 already in use"
SOLUTION: Use different port
$ npx remotion studio --port 3001

ERROR: "Out of memory"
SOLUTION: Reduce quality or use single core
$ npx remotion render HackathonDemo_Oern --quality=50
$ npx remotion render HackathonDemo_Oern --concurrency=1

ERROR: "Composition not found"
SOLUTION: Verify registration in Root.tsx
$ npm run dev
(Check if HackathonDemo_Oern appears in list)

ERROR: "Rendering failed"
SOLUTION: Clear cache and retry
$ rm -rf node_modules .next
$ npm install
$ npx remotion render HackathonDemo_Oern
